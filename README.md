<h1>JavaScript Calculator</h1>

<p>A simple calculator built with HTML, CSS, and JavaScript. It supports basic arithmetic operations through a clean and easy-to-use interface.</p>

<h2>Features</h2>

<ul> 
<li>Addition</li> 
<li>Subtraction</li> 
<li>Multiplication</li> 
<li>Division</li> 
<li>Decimal numbers</li>
<li>Clear/reset functionality</li> 
</ul>

<h2>Technologies Used</h2>

<ul> 
<li>HTML</li> 
<li>CSS</li> 
<li>JavaScript</li> 
</ul>

<h2>Project Purpose</h2>

<p>This project was created as part of <strong>The Odin Project</strong> to strengthen my understanding of JavaScript fundamentals, DOM manipulation, event handling, and building interactive webpages.</p>
